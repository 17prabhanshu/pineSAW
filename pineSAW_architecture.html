NLP False-Positive Fix — Word Boundary Regex

Discovered a critical false-positive bug: classifier.py used Python substring matching causing innocent words to trigger drug alerts — "fe" in "safe", "ice" in "police", "meth" in "methodology".

❌
[kw for kw in KEYWORDS if kw in text_lower]
✅
re.search(r'\b' + re.escape(kw) + r'\b', text)
→
Wikipedia OSINT page went from "HIGH THREAT" false positive to correctly "LOW" with zero false narcotics matches

Network Graph Replaced with ECharts 2D ★ New

The jiggly 3D Three.js force graph was replaced with Apache ECharts — same enterprise visualization engine used by Palantir and GitLab. Dramatically smoother physics, adjacency-focus hover, cinematic node glow.
